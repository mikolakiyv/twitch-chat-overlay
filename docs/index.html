Как запустить

  1. Скачайте TwitchChatOverlay.exe кнопкой выше — устанавливать ничего не нужно.
  2. Запустите и введите название канала (можно несколько через запятую).
  3. Готово: перетаскивайте за верхнюю полосу, правый клик или ⚙ — настройки, F9 — только текст, F8 — сквозные клики.

⚠️ Windows SmartScreen при первом запуске: «Подробнее» → «Выполнить в любом случае» — стандартное предупреждение для программ без платной цифровой подписи. Код открыт, можно проверить на GitHub.
